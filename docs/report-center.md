# 报表统计功能

## 页面与操作

系统“报表统计”入口加载七类报表：采购询比价、入库、出库、当前仓库库存、当前基地库存、基地调拨、备用金支出。

统一提供日期区间、项目、材料关键词、单位筛选；采购和入库支持供应商筛选。查询按钮应用筛选；本月、上月为快捷查询；重置回到本月及全部授权项目。

顶部显示本次已应用筛选、金额和笔数。下方通过按钮切换统计视图，前三类采购汇总附前十名条形图。各表每页50条，Excel按已应用筛选导出全部结果，不受页码影响。采购导出同时包含项目、供应商、材料排名、材料明细、运费明细和核对事项。

## 统计口径

| 业务 | 日期字段 | 金额与笔数 |
| --- | --- | --- |
| 采购 | 询价日期，含起止日 | 只统计已同意单据；选定报价单价乘数量，逐行四舍五入至分；运费按询价单与选定供应商计一次 |
| 入库、出库 | 实际入库或出库时间，含起止日 | 汇总业务明细金额；单据ID去重计笔数 |
| 仓库库存 | 当前快照，禁用日期筛选 | 非零库存数量乘库存单价；项目只筛选该项目曾入库的同仓同材料，不能视为项目独立存量 |
| 基地库存 | 当前快照，禁用日期筛选 | 来源项目、地区及非零现存数量；金额为数量乘库存单价 |
| 基地调拨 | 调拨时间，含起止日 | 按调入项目汇总；折旧单价乘数量加运费，批次去重计笔数，无批次使用调拨单号 |
| 备用金 | 支出日期，含起止日 | 包含已报销支出历史，按当前报销状态分列；期间支出不能当作余额 |

采购供应商按供应商编号区分，采购笔数按“供应商＋询价单”去重，一单多供应商时供应商笔数之和可以大于询价单数。

材料数量与金额按材料编号、规格、详细规格、单位分组。数量按单位分别排名，不自动换算、不合并同名异规格或跨地区材料。使用材料/单位筛选时只汇总命中材料的货款，不分摊整单运费。

当前业务中 `purchase_inquiry_items.selected_quote_id` 保存的是供应商编号。报表优先使用整单供应商，再使用材料指定供应商；均无指定时使用明确选中报价，最后兼容唯一的最低价标记。选定报价不明确或缺失时列核对事项。旧结构只在该单没有新结构材料项时使用；旧数据缺少数量时不假定数量为1。

单据主表金额和逐行材料金额加运费的差异在核对表展示，包括历史小数精度差异。已审批但明细不全的单据仍计入询价单笔数，未能计算的金额不假定为完整金额。核对表覆盖日期和项目范围，不跟随供应商、材料筛选。

采购、出入库、备用金属于不同业务环节，分别展示，不能直接累加为总采购成本。

## 权限及实现

报表与导出均要求登录并读取数据库中的当前有效角色。系统管理员查看全部；材料员、材料审批负责人、基地负责人查看绑定项目；无绑定项目为空结果，越权项目请求返回403，供应商不可访问内部报表。

只读查询使用同一数据库快照完成汇总和明细读取，不更改业务记录。页面与Excel共用统计方法。导出文本作为字面值写入，避免材料/供应商名称被Excel解释为公式。

接口：`GET /api/reports/options`、`GET /api/reports`、`GET /api/reports/export`。参数：`kind`、`start_date`、`end_date`、`project_id`、`supplier_id`、`keyword`、`unit`；分页为 `page_<视图标识>`。

金额去重、截止日、审批状态、授权范围、旧结构缺失、单位分组、库存关联、调拨及备用金、分页与完整Excel导出由 `tests/test_reports.py` 验证。
