# 询比价供应商整单运费设计

## 目标

将材料含税单价与物流运费分开报价。每个供应商针对一张询比价单填写一笔含税运费；系统以“全部材料货款合计 + 一笔运费”作为该供应商的到货总价，用于整单比价、拟定供应商、审批和导出。

## 已确认规则

- 运费按“询比价单 + 供应商”保存，不按材料行保存或分摊到材料单价。
- 运费填写含税金额，同时保存税率和自动计算的不含税金额。
- 拟定和审批时整张单只能选择一家供应商；该供应商负责整车配送全部材料。
- 供应商到货总价 = 该供应商全部材料货款 + 一笔含税运费。
- 库内价比对继续只比较材料单价；历史单据没有运费记录时按 0 处理。

## 涉及流程

- 管理端询比价编辑：显示供应商整单汇总，填写运费并整单拟定供应商。
- 供应商门户：材料单价表之外填写一次整单运费，保存、提交和锁定状态与报价一致。
- 详情、审批、Excel 比价表和供应商供货单：分别展示货款、运费、到货总价。
- 对账：材料货款维持原有明细，运费作为单独明细计入一次。

## 兼容与验收

- 旧单据的接口、审批、查看、导出保持可用且金额不变。
- 服务端重新计算货款、运费不含税额和总额，不信任客户端传入的合计。
- 不允许拟定多家供应商，也不允许拟定未报齐全部材料的供应商。
