# 采购询比价审批签字单改版设计

## 目标

将采购询比价审批签字单改成接近桌面模板 `询价表_CGXJ-260611-001.xlsx` 的横向 Excel 风格打印页，让审批人能快速看清材料、供应商报价、最低价、拟定供应商、拟定金额和签字区。

## 版式

- 使用 A4 横向打印。
- 顶部为合并式标题：`零星材采购比价审批签字单`。
- 第二行为项目和单据信息，格式贴近模板：
  - 左侧：`项目名称：城市 / 项目编码 / 项目名称`
  - 右侧：`时间：询价日期　单号：询价单号`
- 主表横向展示：
  - 固定列：序号、材料名称、规格型号、详细规格、品牌、是否国标、单位、数量。
  - 供应商列：每个供应商占一列，单元格展示 `单价 / 总价`。
  - 末尾列：拟定供应商。
- 最低价报价用浅绿背景和 `★` 标记。
- 拟定供应商按 `is_selected = 1` 展示；没有拟定时为空。

## 合计区

- 主表下方显示各供应商拟定商品合计，例如：`佩文筛网：¥40.00 | 捷阳五金：¥21.00`。
- 同一区域显示总拟定合计和大写金额。

## 签字和审批

- 签字区只保留三栏：
  - 申请人签字
  - 材料员签字
  - 项目负责人签字
- 项目管理处审批记录保留在签字区下方，沿用当前审批记录表逻辑。
- 不显示总经理签字。

## 兼容性

- 新版优先用于 `purchase_inquiry_items + purchase_inquiry_quotes` 新结构。
- 旧结构数据继续保留可打印能力，使用简化横向明细表。
- 数据不足时用 `-` 占位，避免打印页报错。

## 验收

- 打印 HTML 中出现横向 Excel 风格标题、项目行、供应商横向报价列。
- 各供应商拟定合计正确显示。
- 签字区只包含申请人、材料员、项目负责人。
- 项目管理处审批记录仍显示。
- 相关后端测试通过。
